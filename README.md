# 汝心科技 · Claude 技能库

公司内部共用的 Claude 技能（Skills）。本仓库为私有仓库，请勿公开或外传。

## 技能列表

| 技能 | 用途 |
|---|---|
| [ruxin-four-step-method](.claude/skills/ruxin-four-step-method/SKILL.md) | 汝心四步法：看清现象 → 确认测量和数据 → 验证解决办法 → 定下一步（谁做、哪天前）。用于排障、质量问题、项目卡点，以及检查别人的排障回答。 |

## 怎么用

- **Claude Code**：在本仓库里开会话，`.claude/skills/` 下的技能会自动加载。
- **Claude 网页 / App**：下载对应技能文件夹，打包成 zip，在设置的技能页面上传。
